# LEGENDS — Football Jersey Store

A responsive black-and-white football jersey storefront built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — full storefront, collection, contact, cart and payment modal.
- `style.css` — responsive visual design.
- `script.js` — products, filters, cart, localStorage, checkout and contact interactions.
- `assets/hero-rivalry.png` — the hero artwork supplied for the design.

## Run
Open `index.html` in a browser. No build tools are required.

## Customize
Edit the `products` array at the top of `script.js` to change names, prices and categories.
Replace `assets/hero-rivalry.png` to use another hero image.

Note: the payment form is a front-end demo. Connect it to a real payment provider/backend before accepting real payments.
